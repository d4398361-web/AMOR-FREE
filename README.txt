AMOR HOSTING
============
Run:        pip install -r requirements.txt && python main.py
VPS admin:  /vps-admin   (login is printed in the terminal on first run)
Customers:  /vps/signup -> order at /vps -> console at /vps/panel
Optional env: OPENAI_API_KEY (assistant), VPS_WEBHOOK_URL, TELEGRAM settings as before.
IMPORTANT: customer code runs on this machine. Use a dedicated server or containers.
